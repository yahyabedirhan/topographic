    topographic· documentation

    Contour lines of real and made-up land, drawn live in 2D and 3D.

    /docs·7 landforms·10 locations·0.5.0, names for 0.6.0·Install ↓

    Most terrain on the web is a picture: a still image, or a video that loops. topographic draws the land itself, as contour lines that move, from a few settings or from real elevation data, and it draws the same land every time.

    This page is the whole library. Every setting is here with its range and default, every figure is the real library running in this page, and every example is the code you would write. Proposed names are marked .

    topographic is Apache 2.0, by Yahya Bedirhan Pak. Heights from Mapzen Terrain Tiles on AWS Open Data; map images from OpenFreeMap, OpenMapTiles and OpenStreetMap.

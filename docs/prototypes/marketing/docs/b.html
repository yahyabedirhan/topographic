topographic docs

Real and made-up land, as contour lines, in 2D and 3D.

topographic is a small WebGL library for topographic terrain. Use it on a website, render it into a video, or draw the maps and screens of a game. Scroll: the terrain beside this text is the library, and it changes with every section.

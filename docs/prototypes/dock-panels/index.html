One anchor, one row grid

Topographic playground · cluster, popovers and dock · mockup on real CSS tokens

Anchor

Every popover opens under the cluster, right-aligned, 10px below it. Cluster order: Place, 2D/3D, Tune, Export. Widths: 380 (Tune, Export) and 560 (Place). Padding 14/16/16, radius 22.

Header

Sentence-case title, 13px semibold, one accessory on the right. Then a full-width tab bar (icon over label) where a popover has tabs. Labels on tabs mean no tooltips that cover content.

Row grid

80px | 1fr | 40px, gap 12, rows 34px. Label 12.5px ink, value 12px muted, tabular, right-aligned. Numbers are sliders; choices are segmented controls spanning control and value columns.

Sections

10.5px uppercase muted header, 26px tall, one ↺ reset per group (shown only when changed). 10px + hairline + 10px between groups, 0 between rows. Look controls live only in the dock.

# Landing page example

A React and Vite landing page for an imaginary company, Northwind Surveyors.
It uses the published `topographic-react` package, not the workspace copy.
The background is Everest in 3D with an orbiting camera.

## Steps

1. Install the dependencies: `npm install`
2. Start the dev server: `npm run dev`
   - Result: the page opens in your browser.

## Notes

The terrain is one `<Topography>` element (Everest, 3D, endless plane) in `src/App.jsx`.
Change `location`, `mode` or `camera` there to try other places and camera paths.
